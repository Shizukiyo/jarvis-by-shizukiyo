# J.A.R.V.I.S. — голосовой ассистент для Windows

Простой голосовой помощник в консоли: слушает микрофон, реагирует на слово **«Джарвис»**, выполняет команды на компьютере, а на всё остальное отвечает через **локальную нейросеть** (Ollama). У него есть ASCII-лицо, которое меняет «настроение» в зависимости от состояния.

```
╭───────────────╮
│               │
│   ◉       ◉   │
│               │
│      ▂▃▂      │
│               │
╰───────────────╯
```

## Возможности

- Достаточно один раз сказать **«Джарвис»**: дальше идёт живой диалог без повторения слова. Через 2 минуты тишины или по слову «пока» он уходит в режим ожидания
- Команды: сайты и программы, поиск в Google, таймеры и напоминания, заметки, громкость, скриншоты, дата и время
- Музыка: «включи Imagine Dragons» ищет в Яндекс Музыке и (после одноразовой калибровки) сразу запускает, плюс пауза и переключение треков
- Остальное обсуждает локальная нейросеть (Ollama): без подписок и лимитов, с настраиваемым характером и памятью разговора (помнит до 30 вопросов и ответов, даже после перезапуска)
- Выключение и перезагрузка компьютера только после голосового подтверждения
- Озвучивает ответы голосом Windows, скорость и голос настраиваются
- Его можно перебить в любой момент: просто заговори, пока он говорит, и он замолчит и выслушает
- Аватар в консоли: ожидание, слушает, думает, говорит

## Требования

- Windows 10/11
- **Python 3.11 или 3.12** (на 3.13 и новее у PyAudio может не быть готового пакета, и установка упадёт)
- Микрофон
- Интернет для распознавания речи (используется сервис Google, см. «Приватность»)
- Для нейросети: видеокарта с 8+ ГБ видеопамяти (или 16+ ГБ ОЗУ, но будет медленнее)
- Рекомендуется Windows Terminal (в старой консоли часть символов аватара может отображаться криво)

## Установка

### 1. Установи Python

Скачай Python 3.11 или 3.12 с [python.org/downloads](https://www.python.org/downloads/). В установщике обязательно поставь галочку **Add Python to PATH**.

```
python --version
```

### 2. Скачай проект

```
git clone https://github.com/Shizukiyo/jarvis-by-shizukiyo.git
cd jarvis-by-shizukiyo
```

Или нажми **Code → Download ZIP** на странице репозитория и распакуй.

> В cmd для смены диска используй `cd /d G:\путь\к\папке`. Обычный `cd` диск не меняет.

### 3. Создай виртуальное окружение

```
py -3.11 -m venv .venv
.venv\Scripts\activate
```

(Если у тебя 3.12, пиши `py -3.12`.) В начале строки появится `(.venv)`. Список установленных версий: `py -0`.

### 4. Установи зависимости

```
python -m pip install -r requirements.txt
```

Если упала сборка PyAudio (`Failed building wheel for PyAudio`), у тебя слишком новая версия Python. Поставь 3.11 или 3.12 и повтори шаг 3.

### 5. Установи Ollama и скачай модель

1. Скачай Ollama с [ollama.com](https://ollama.com) и установи. Дальше она работает фоновой службой.
2. Скачай модель:

```
ollama pull gemma4:12b
```

Подбери модель под свою видеокарту (актуальный список на [ollama.com/library](https://ollama.com/library)):

| Видеопамять | Что пробовать |
|---|---|
| 4-6 ГБ | модели 1-4B (например `qwen3.5:4b`) |
| 8 ГБ | модели 7-9B (например `qwen3.5:9b`) |
| 12 ГБ | `gemma4:12b`, модели до 14B |
| 24 ГБ и больше | модели 27B и выше |

Название модели меняется в начале `jarvis.py` в переменной `MODEL`.

**Хранить модели на другом диске.** Закрой Ollama (значок в трее → Quit), задай переменную и запусти Ollama заново:

```
setx OLLAMA_MODELS "D:\ollama\models"
```

После этого открой **новый** терминал и качай модель.

### 6. Поставь русский голос Windows

**Параметры → Время и язык → Речь → Добавить голоса**. Без русского голоса Джарвис будет говорить по-русски с сильным акцентом.

### 7. Проверь микрофон

**Параметры → Система → Звук → Ввод**: выбери нужный микрофон и убедись, что полоска громкости двигается, когда ты говоришь.

## Запуск

```
python jarvis.py
```

Или двойной клик по `start_jarvis.bat` (он сам включит окружение).

Скажи: **«Джарвис»**, а потом просто говори. Подробнее о режимах диалога ниже.

## Как с ним общаться

**Режим диалога.** Скажи «Джарвис» один раз (можно сразу с командой: «Джарвис, открой ютуб»). После этого он слушает и отвечает без слова-активатора, пока ты не замолчишь на 2 минуты (`SESSION_TIMEOUT`) или не скажешь в конце фразы «пока», «отбой», «свободен», «спокойной ночи», «отдыхай», «спи», «засыпай», «иди спать», «на сегодня всё» и подобное. Дальше он снова ждёт слово «Джарвис».

Чтобы полностью закрыть программу: «Джарвис, выключись» или `Ctrl+C`.

> В режиме диалога распознаётся всё, что слышит микрофон. Если рядом работает телевизор или идёт разговор, Джарвис может принять это за обращение к себе. В этом случае скажи «пока» или используй наушники с микрофоном.

## Музыка (Яндекс Музыка)

Фразы вида «включи Imagine Dragons», «поставь песню Believer», «включи трек дождь в яндекс музыке» открывают поиск Яндекс Музыки в браузере. Чтобы музыка ещё и **начинала играть сама**, нужна одноразовая калибровка: Джарвис должен знать, где на странице находится кнопка play, и он кликнет по ней через несколько секунд после открытия.

**Калибровка (один раз):**

1. Запусти `python jarvis.py --music-calibrate`
2. Пока идёт отсчёт, открой в браузере music.yandex.ru, найди любой трек поиском и наведи курсор на кнопку play у первого результата. Не кликай, просто держи курсор там
3. Через 10 секунд программа выведет строку вида `MUSIC_CLICK = (640, 410)`
4. Впиши её в начале `jarvis.py`

Дальше при команде «включи ...» он откроет поиск, подождёт `MUSIC_DELAY` секунд (по умолчанию 4, увеличь при медленном интернете) и нажмёт на кнопку.

Ограничения, о которых лучше знать:

- Клик идёт по координатам внутри окна браузера, поэтому окно должно быть в том же состоянии, что и при калибровке (лучше развёрнуто на весь экран), и тот же масштаб страницы. Если Яндекс сильно поменяет вёрстку, калибровку нужно повторить
- Нажимается кнопка у первого результата поиска. Для имени исполнителя это обычно его популярные треки, для названия песни сама песня
- Работает с сайтом в браузере по умолчанию. Если ты слушаешь в отдельном приложении «Яндекс Музыка», оно таким способом не управляется
- Управление паузой и переключением треков работает через системные медиа-клавиши (в приложении и в браузере)
- «Включи ...» воспринимается как музыка почти для любого слова. Исключения (звук, свет, таймер, компьютер и т.п.) заданы в `NOT_MUSIC`

## Промпт Джарвиса (его характер)

Манера общения задаётся переменной `PERSONA` в начале `jarvis.py`. Это системный промпт: инструкция, которую модель получает перед каждым ответом. Вот он целиком:

> Ты Джарвис: голосовой ассистент и собеседник, чем-то похожий на Джарвиса из «Железного человека». Ты умный, внимательный, с мягким юмором и тёплой иронией. Говори живо, как умный друг, а не как справочник: разговорный русский, без канцелярита и без пафоса. Обычно отвечай двумя-четырьмя предложениями; если тема интересная или человек просит рассказать подробнее, можно длиннее. Поддерживай диалог: реагируй на настроение собеседника, помни, о чём вы говорили, иногда (но не каждый раз) задавай один встречный вопрос. Не извиняйся без нужды и не повторяй, что ты искусственный интеллект. Если чего-то не знаешь, скажи об этом честно и коротко. Действия на компьютере (открыть программу, таймер, громкость, заметки) выполняет отдельный модуль по чётким командам. Сам ты их не выполняешь, поэтому никогда не говори, что что-то открыл, включил или сделал. Твой ответ будет озвучен голосом: никакого markdown, списков, эмодзи и скобок, числа и сокращения пиши так, как их легко произнести вслух.

К нему при каждом запросе автоматически добавляется:

- твоё имя (`USER_NAME`), если оно задано
- последние 15 заметок из `jarvis_notes.txt`, чтобы он помнил то, что ты просил запомнить
- текущая дата и время

**Как менять.** Просто перепиши текст `PERSONA`. Несколько идей:

- Другой стиль: «Ты язвительный, но добрый помощник, любишь сухой британский юмор», «Ты спокойный наставник, объясняешь просто и с примерами»
- Другая длина: замени «двумя-четырьмя предложениями» на «одним-двумя» для коротких реплик или на «подробно» для лекций
- Обращение: «Обращайся к собеседнику на «ты» и по имени»
- Тематика: «Ты разбираешься в программировании, предлагай примеры кода словами»

**Что лучше не удалять:**

- Фразу про то, что ответ озвучивается и без markdown и списков, иначе голос начнёт зачитывать звёздочки и номера
- Фразу про то, что действия на компьютере выполняет отдельный модуль, иначе модель будет говорить «Готово, открыл ютуб», ничего не открыв

Если после правок ответы стали странными, верни исходный текст из этого раздела.

## Память

Джарвис помнит разговор в рамках настроек:

```python
HISTORY_MESSAGES = 60         # сколько последних реплик помнить (60 = 30 вопросов и ответов)
CONTEXT_TOKENS = 8192         # «окно» модели в токенах
REMEMBER_BETWEEN_RUNS = True  # сохранять память между запусками (файл jarvis_memory.json)
```

- В память попадают и обычные вопросы, и выполненные команды, поэтому можно спросить «а что ты только что открывал?»
- Когда реплик становится больше лимита, самые старые забываются
- `CONTEXT_TOKENS` ограничивает, сколько текста модель реально видит за раз. Чем больше, тем лучше она держит нить длинного разговора, но тем больше нужно видеопамяти и тем медленнее ответы. Если модель стала тормозить или не влезает в видеокарту, уменьши до 4096 и сократи `HISTORY_MESSAGES`
- «Забудь всё» или «начнём сначала» очищает память разговора, но не трогает заметки («запомни, что ...»)
- Файлы `jarvis_memory.json` и `jarvis_notes.txt` личные, они добавлены в `.gitignore`, чтобы не попасть в репозиторий

## Как он слушает

Микрофон открыт всё время, запись и распознавание идут в отдельных потоках. Благодаря этому слова не теряются, пока предыдущая фраза ещё распознаётся. Дополнительно:

- Если сделать паузу посреди фразы, она не режется на две части: тишина дольше `LISTEN_PAUSE` секунд (по умолчанию 1.2) считается концом фразы
- Одна фраза может длиться до `PHRASE_LIMIT` секунд (по умолчанию 30)
- Пока нейросеть думает над ответом, он продолжает слушать: если ты договариваешь мысль, вопрос склеивается и задаётся заново с полной фразой, а если говоришь «стоп», ответ отменяется
- Пока Джарвис говорит, работает перебивание (см. ниже)

Если он всё равно режет длинные фразы, увеличь `LISTEN_PAUSE` до 1.5-2. Если реагирует слишком медленно после того, как ты замолчал, уменьши до 0.8-1.

## Настройка голоса

В начале `jarvis.py`:

```python
VOICE_RATE = 2      # скорость: от -10 до 10, 0 = обычная
VOICE_VOLUME = 100  # громкость: 0-100
VOICE_NAME = ""     # часть названия голоса, пусто = автоматически русский
```

**Как сменить голос:**

1. Посмотри, какие голоса установлены: `python jarvis.py --voices`
2. Впиши часть названия нужного голоса в `VOICE_NAME`, например `"Pavel"`
3. Новые голоса добавляются в **Параметры → Время и язык → Речь → Добавить голоса**

Некоторые новые «естественные» голоса Windows (те, что используют экранный диктор) сторонним программам недоступны и в списке не появятся.

### Перебивание

Пока Джарвис говорит, он продолжает слушать микрофон. Стоит тебе заговорить, и он сразу ставит речь на паузу, дослушивает твою фразу и решает, что делать:

- Если сказал «стоп», «хватит», «замолчи», «тихо» — он просто замолкает
- Если сказал новую фразу (в диалоге слово «Джарвис» не нужно) — он обрывает ответ и сразу выполняет её
- Если это был шум или эхо его собственного голоса — он продолжает с того же места

Это работает лучше всего **в наушниках**. С колонками микрофон слышит и самого Джарвиса: программа отличает его эхо по тексту, но он может спотыкаться и делать паузы. Если он «перебивает сам себя», увеличь `BARGE_FACTOR` (например, до 2.5-3), если наоборот не замечает тебя, уменьши до 1.2. Полностью выключить можно через `ALLOW_INTERRUPT = False`.

## Как добавить свою команду

Напиши функцию по шаблону и добавь в список `HANDLERS`:

```python
def cmd_my_notes(cmd: str, ears: Ears):
    if "открой заметки" in cmd:
        subprocess.Popen("notepad C:\\notes.txt")
        return "Открываю заметки"
    return None   # None = команда не подошла, пробуем следующую

HANDLERS = [cmd_power, cmd_timer, cmd_my_notes, cmd_volume, cmd_time, cmd_search, cmd_open]
```

Если ни одна функция не подошла, вопрос уходит в нейросеть. Опасные действия всегда делай через `confirm(ears, "Точно?")`.

Сайты и программы для «открой ...» добавляются в словари `SITES` и `APPS` (ключ — корень слова, как его произносят).

## Сборка в .exe

Дважды кликни `build_exe.bat` (или выполни его команды вручную). Готовая программа появится в `dist\Jarvis\Jarvis.exe`. Папку `Jarvis` нужно хранить целиком, можно сделать ярлык на `Jarvis.exe`.

Заметки:

- Ollama и модель нужно ставить отдельно, в exe они не входят
- Антивирусы иногда ругаются на программы, собранные PyInstaller. Если так, добавь папку в исключения
- Вариант «один файл» делается заменой `--onedir` на `--onefile`, но он стартует медленнее и чаще попадает под подозрение антивируса

## Частые проблемы

| Проблема | Решение |
|---|---|
| `Failed building wheel for PyAudio` | Нужен Python 3.11 или 3.12 |
| `ModuleNotFoundError: No module named ...` | Не включено окружение (`.venv\Scripts\activate`) или не установлены зависимости |
| `OSError: No Default Input Device` | Не выбран микрофон в настройках звука Windows |
| Не реагирует на «Джарвис» | Добавь вариант написания в `WAKE_RE` (иногда распознаётся как «жарвис») |
| «Нет связи с сервисом распознавания» | Проверь интернет |
| «Не могу достучаться до нейросети» | Запущена ли Ollama? `ollama list` показывает модель? Текст ошибки печатается в консоль |
| Ошибка 503 от Ollama при том, что в консоли всё работает | Прокси или VPN. В коде уже отключено, но можно добавить `setx NO_PROXY "localhost,127.0.0.1"` |
| Модель отвечает долго | Возьми модель поменьше или уменьши `CONTEXT_TOKENS` |
| Фразы режутся или теряются | Увеличь `LISTEN_PAUSE` (см. «Как он слушает») |
| Странный акцент в озвучке | Установи русский голос Windows (шаг 6) |
| Джарвис слышит сам себя или постоянно останавливается | Используй наушники или увеличь `BARGE_FACTOR` |
| Не замечает, что я его перебиваю | Уменьши `BARGE_FACTOR` или говори чуть громче |

## Приватность

Распознавание речи использует `recognize_google`, поэтому **всё, что слышит микрофон, отправляется в сервис Google**: программа распознаёт речь целиком, а слово «Джарвис» ищет уже в тексте. Во время ответа Джарвиса микрофон тоже слушает (чтобы можно было перебить), а в режиме диалога на распознавание уходит каждая услышанная фраза. Нейросеть и озвучка работают локально. Если нужен полностью офлайн-режим, замени распознавание на [Vosk](https://alphacephei.com/vosk/) или faster-whisper.
