# J.A.R.V.I.S. — голосовой ассистент для Windows

Простой голосовой помощник в консоли: слушает микрофон, реагирует на слово **«Джарвис»**, выполняет команды на компьютере, а на всё остальное отвечает через **локальную нейросеть** (Ollama). У него есть ASCII-лицо, которое меняет «настроение» в зависимости от состояния.

```
╭───────────────╮
│               │
│   ◉       ◉  │
│               │
│     ▂▃▂    │
│               │
╰───────────────╯
```

## Возможности

- Реагирует только на фразы со словом «Джарвис», всё остальное игнорирует
- Команды: открыть сайт или программу, поиск в Google, громкость, время
- Выключение и перезагрузка компьютера только после голосового подтверждения
- Любой другой вопрос уходит в локальную нейросеть (без подписок и лимитов)
- Озвучивает ответы офлайн-голосом Windows
- Аватар в консоли: ожидание, слушает, думает, говорит

## Требования

- Windows 10/11
- Python 3.10-3.12 (рекомендуется 3.11 или 3.12)
- Микрофон
- Интернет для распознавания речи (используется сервис Google, см. «Приватность»)
- Для нейросети: видеокарта с 8+ ГБ видеопамяти (или 16+ ГБ ОЗУ, но будет медленнее)

## Установка

### 1. Установи Python

Скачай с [python.org/downloads](https://www.python.org/downloads/). В установщике обязательно поставь галочку **Add Python to PATH**.

Проверка в терминале (PowerShell или cmd):

```
python --version
```

### 2. Скачай проект

```
git clone https://github.com/Shizukiyo/jarvis-by-shizukiyo.git
cd jarvis-by-shizukiyo
```

Или нажми **Code → Download ZIP** на странице репозитория и распакуй.

### 3. Создай виртуальное окружение (рекомендуется)

```
python -m venv .venv
.venv\Scripts\activate
```

### 4. Установи зависимости

```
pip install -r requirements.txt
```

**Если не ставится PyAudio** (самая частая проблема на Windows):

```
pip install pipwin
pipwin install pyaudio
```

Если и это не помогло, скачай готовый `.whl` под свою версию Python и поставь его командой `pip install путь\к\файлу.whl`. Проще всего сменить Python на 3.11 или 3.12.

### 5. Установи Ollama и скачай модель

1. Скачай Ollama с [ollama.com](https://ollama.com) и установи. Дальше она работает фоновой службой.
2. Скачай модель:

```
ollama pull gemma4:12b
```

Подбери модель под свою видеокарту (актуальный список на [ollama.com/library](https://ollama.com/library)):

| Видеопамять    | Что пробовать                       |
| -------------- | ----------------------------------- |
| 4-6 ГБ         | модели 1-4B (например `qwen3.5:4b`) |
| 8 ГБ           | модели 7-9B (например `qwen3.5:9b`) |
| 12 ГБ          | `gemma4:12b`, модели до 14B         |
| 24 ГБ и больше | модели 27B и выше                   |

Название модели меняется в начале `jarvis.py` в переменной `MODEL`. Если тега нет в библиотеке, выбери любой доступный.

### 6. Поставь русский голос Windows

Для озвучки нужен русский голос: **Параметры → Время и язык → Речь → Добавить голоса**. Без него Джарвис будет говорить по-русски с сильным акцентом.

### 7. Проверь микрофон

**Параметры → Система → Звук → Ввод**: выбери нужный микрофон и убедись, что полоска громкости двигается, когда ты говоришь.

## Запуск

```
python jarvis.py
```

Скажи: **«Джарвис, который час?»**

Для выхода скажи «Джарвис, пока» или нажми `Ctrl+C`.

## Примеры команд

| Фраза                             | Что произойдёт                                        |
| --------------------------------- | ----------------------------------------------------- |
| Джарвис, открой ютуб              | Откроется YouTube                                     |
| Джарвис, открой блокнот           | Запустится блокнот                                    |
| Джарвис, найди рецепт борща       | Поиск в Google                                        |
| Джарвис, сделай громче / тише     | Громкость                                             |
| Джарвис, сколько времени          | Озвучит время                                         |
| Джарвис, выключи компьютер        | Спросит подтверждение, потом выключит через 10 секунд |
| Джарвис, расскажи про чёрные дыры | Ответит нейросеть                                     |

Отмена выключения: `shutdown /a` в терминале.

## Как добавить свою команду

Открой `jarvis.py`, напиши функцию по шаблону и добавь её в список `HANDLERS`:

```python
def cmd_notes(cmd: str, ears: Ears):
    if "открой заметки" in cmd:
        subprocess.Popen("notepad C:\\notes.txt")
        return "Открываю заметки"
    return None   # None = команда не подошла, пробуем следующую

HANDLERS = [cmd_shutdown, cmd_volume, cmd_time, cmd_search, cmd_notes, cmd_open]
```

Если ни одна функция не подошла, вопрос уходит в нейросеть. Опасные действия всегда делай через `confirm(ears, "Точно?")`.

Сайты и программы для «открой ...» добавляются в словари `SITES` и `APPS` в начале файла.

## Частые проблемы

| Проблема                             | Решение                                                                 |
| ------------------------------------ | ----------------------------------------------------------------------- |
| `OSError: No Default Input Device`   | Не выбран микрофон в настройках звука Windows                           |
| Не реагирует на «Джарвис»            | Добавь вариант написания в `WAKE_RE` (иногда распознаётся как «жарвис») |
| «Нет связи с сервисом распознавания» | Проверь интернет                                                        |
| «Проверь, запущена ли Ollama»        | Запусти Ollama и проверь `ollama list`, что модель скачана              |
| Модель отвечает долго                | Возьми модель поменьше                                                  |
| Странный акцент в озвучке            | Установи русский голос Windows (шаг 6)                                  |
| Джарвис слышит сам себя              | Используй наушники или отодвинь микрофон от колонок                     |

## Приватность

Распознавание речи использует `recognize_google`, поэтому **аудио после слова-активатора и до него отправляется в сервис Google**, ведь программа распознаёт всё, что слышит, а слово «Джарвис» ищет уже в тексте. Нейросеть и озвучка работают локально. Если нужен полностью офлайн-режим, замени распознавание на [Vosk](https://alphacephei.com/vosk/) или faster-whisper.
